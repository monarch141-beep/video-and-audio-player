# HTML Audio and Video Player Lab 🎵🎥

A web page built to practice embedding responsive HTML5 audio and video elements with custom media attributes.

---

## 📌 Project Overview
This lab showcases native HTML5 media integration using semantic elements.

### Key Features Implemented:
- **HTML5 Video Player:** Embedded MP4 video with explicit (width), (controls), and continuous (loop) playback attributes.
- **HTML5 Audio Player:** Integrated audio track ("Sailing Away") featuring native browser controls and looping capabilities.
- **Semantic Structure:** Organized media components within clean, accessible HTML layout sections.

---

## 🛠️ Technologies Used
- **HTML5** (Semantic Media Elements & Attributes)
